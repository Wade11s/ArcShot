## 观察到的 AX 事实（供后续功能沿用）

- 节点需要元素同时有 `id` 与非 `GenericContainer` 的 `role`；装饰不给 id 即可不
  上报（0.3.11 没有 `aria_hidden`）。
- `.child("文字")` 不上报；可读文本必须是 `Text`（`text!` 宏或 `Text::new`），
  agent-desktop 读到的是 `statictext` 的 `value`。
- 控件名来自 `aria_label`，外部稳定标识来自 `accessibility_id`（macOS
  `AXIdentifier`，agent-desktop 的 `native_id`）。
- `AXPress` 不会触发 `on_click`；每个可操作控件都显式注册
  `on_a11y_action(AccessibleAction::Click, …)`，并与点击路径入同一个 `UiQueue`。
- Accessibility 懒激活：窗口刚打开时第一次 `snapshot --app` 可能是空树，必须重读。
- 覆盖层仍不出现在 `list-windows`（非激活 borderless），只能由
  `snapshot --app` 观察，属观察缺口而非功能缺口。
